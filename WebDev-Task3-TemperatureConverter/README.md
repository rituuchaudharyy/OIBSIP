# Temperature Converter Website

An interactive temperature converter website developed as part of the Oasis Infobyte Web Development Internship – Level 1 Task 3.

## Objective

Build an interactive web tool that converts temperature values between Celsius, Fahrenheit, and Kelvin with real-time input validation and proper error handling.

## Features

- Numeric input field for temperature values
- Input unit selection: Celsius, Fahrenheit, or Kelvin
- Conversion to all temperature units
- Convert button for calculation
- Displays converted values with correct unit labels
- Rejects invalid/non-numeric input
- Handles absolute zero violations with a user-friendly error message
- Clean and centered user interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Temperature Conversions

- Celsius to Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit to Celsius: `(F − 32) × 5/9`
- Celsius to Kelvin: `C + 273.15`
- Kelvin to Celsius: `K − 273.15`
